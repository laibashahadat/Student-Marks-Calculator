# 🎓 Student Marks Calculator

A simple **Student Marks Calculator** built with Python. This project calculates a student's total marks, percentage, and grade based on subject marks.

## ✨ Features

- 📝 Enter student marks
- ➕ Calculate total marks
- 📊 Calculate percentage
- 🏆 Calculate grade
- 📋 Display student result
- 🐍 Simple Python-based project

## 🛠️ Technologies Used

- Python

## 📚 Subjects

The calculator can be used with subjects such as:

- Mathematics
- Python
- Urdu
- English

## 📊 Grading System

| Percentage | Grade |
|---|---|
| 80% and above | A |
| 70% – 79% | B |
| 60% – 69% | C |
| 50% – 59% | D |
| Below 50% | Fail |

## ▶️ How to Run

1. Make sure Python is installed.
2. Clone the repository:

```bash
git clone https://github.com/laibashahadat/Student-Marks-Calculator.git
```

3. Open the project folder.
4. Run the Python file:

```bash
python "Project 1 .🎓 Student Marks Calculator.py"
```
